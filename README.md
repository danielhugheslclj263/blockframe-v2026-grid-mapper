## What Blockframe Does

Blockframe is meant for turning Minecraft ideas into a clear block grid. Start with an image, then reshape it into an organized canvas so you can work out proportions, placement, and alignment before you build inside the game.

It suits creators who want to use screenshots or reference art without giving up control over the final arrangement. With image import options, grid calibration, and editing controls, Blockframe keeps the path from upload to export straightforward.

---

## Core Capabilities

- Turn screenshots into Minecraft block grids
- Add images through drag and drop, clipboard paste, or the file browser
- Calibrate block size using a reference square
- Build grids automatically from uploaded images
- Modify cells with painting, erasing, and deletion tools
- Check straight lines and spacing with alignment guides
- Export projects as PNG, PDF, JSON, CSV, or print layout
- Save project files and reopen them later for more edits
- Move between dark and light themes
- Work on large canvases with zoom and pan controls

## Using Blockframe

1. Upload a screenshot or other reference image.
2. Set the reference square so the grid matches your intended block scale.
3. Let Blockframe generate the initial block layout.
4. Fine-tune the result with paint, erase, and delete tools.
5. Use alignment guides to review edges, rows, and straight sections.
6. Save the project if you want to continue later.
7. Export the finished work in the format that fits your next step.

Common export choices include:

- PNG for image output
- PDF for printable review
- JSON for structured project data
- CSV for spreadsheet-friendly data
- Print layout for direct paper use
